# NES Emulator for MakeCode Arcade

A lightweight NES emulator running on [MakeCode Arcade](https://arcade.makecode.com/), supporting Mapper 0 (NROM) and Mapper 1 (MMC1/SxROM).

## Supported Games

- **Mapper 0 (NROM):** Donkey Kong, Pac-Man, Ice Climber, Excitebike, Balloon Fight
- **Mapper 1 (MMC1):** Super Mario Bros, The Legend of Zelda, Metroid, Kid Icarus

## Quick Start

1. **Convert your ROM** using the [nes-rom-converter](https://github.com/TycoonCoder/nes-rom-converter) tool:
   ```
   python3 convert.py your-game.nes rom-data.ts
   ```
2. **Copy** `rom-data.ts` into this project folder (replacing the existing one)
3. **Open** this folder in the [MakeCode Arcade editor](https://arcade.makecode.com/)
4. **Run** in the simulator or flash to hardware

## Controls

| Arcade Button | NES Button |
|---|---|
| D-pad | D-pad |
| A | A |
| B | B |
| A + B together | Start |

## Technical Details

- **CPU:** Full 6502 instruction set (56 official opcodes)
- **PPU:** Background tiles, sprites (8x8 and 8x16), scrolling, palette mapping
- **Mappers:** Mapper 0 (NROM) and Mapper 1 (MMC1) with bank switching
- **Display:** NES 256×240 → Arcade 160×120 (centered crop, 2:1 vertical sampling)
- **Colors:** NES 64-color palette mapped to Arcade's 16-color palette via Euclidean closest-match

## ROM Converter

The ROM converter is in a separate repository: [nes-rom-converter](https://github.com/TycoonCoder/nes-rom-converter)

## Limitations

- MakeCode Arcade has a ~256KB program size limit — large ROMs (128KB+ PRG) may not fit
- Only Mapper 0 and Mapper 1 are supported
- No audio emulation (APU not implemented)
- No scanline-based PPU timing — uses frame-level rendering
